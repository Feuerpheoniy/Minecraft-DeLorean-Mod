# Minecraft DeLorean Mod

A Minecraft Bedrock add-on project for a drivable DeLorean-inspired time machine.

## Current status

- Initial Behavior Pack and Resource Pack structure
- DeLorean entity with a driver seat
- Custom low-poly vehicle geometry
- Spawn egg item

## Install

Import the Behavior Pack and Resource Pack folders into Minecraft's development pack folders, or package them as `.mcpack` files. Enable both packs in a test world and enable the required creator experiments if Minecraft prompts for them.

## Notes

This is the first development build. Driving controls and time-travel effects will be added and tested incrementally. The project targets the Bedrock 26.x format family; exact engine compatibility must be verified in-game.
